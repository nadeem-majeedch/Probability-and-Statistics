# Printing practice sets

Every assessment page is designed to print as a usable practice sheet: the questions survive, the
buttons and per-question answers are removed, and the answer key at the end of the page survives so
you can mark the attempt.

## How to print

1. Open the page you want (a module bank or an examination paper).
2. Press `Ctrl + P` (Windows/Linux) or `Cmd + P` (macOS), or use **File → Print**.
3. Choose **Portrait**, margins **Default**, and enable **Background graphics** if your browser
   offers it (the answer-key table uses light shading).
4. Print single-sided if you intend to write working in the margins.

The print stylesheet is in `docs/assets/stylesheets/assessment.css` and applies to every page
built from this site, so no separate PDF is needed.

## What prints and what does not

| Element | Screen | Print |
|---|---|---|
| Question stems and options | Shown | Shown |
| "Check answer" buttons and score | Shown | Hidden |
| Per-question answer and explanation | Collapsible | Hidden |
| Answer-key table | Shown | Shown |
| Worked solutions for written items | Collapsible | Hidden |

This split is deliberate: the printed sheet is a genuine attempt, and the key lets you mark it
without a screen. If you want the solutions on paper, open each answer block before printing and
use your browser's "print selection" on that section, or read the solutions on screen after
marking.

## Marking on paper

Use the answer-key table at the end of each page. For multiple-choice items, a wrong answer is most
useful when you can name the trap: write next to it which distractor you chose and why. For
written items, compare your solution with the model answer and mark each step — setup, formula,
substitution, interpretation — rather than only the final number.

A simple scheme that matches the course's emphasis:

- **2 marks** for a correct method with correct arithmetic.
- **1 mark** for a correct method with an arithmetic slip.
- **0 marks** for a correct number with no working you can follow.
