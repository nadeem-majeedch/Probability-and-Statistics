## A. Problem statement

A network operator measures 1,000 packets across a fibre link and a radio link, recording
packet size, the hour of day and whether the packet was lost. The operator wants to know
the overall loss rate, whether the radio link is worse after accounting for packet size,
how loss scales with size, and whether the network can promise a loss rate below 1 % for
small packets.

## B. Background and context

Packet loss is a Bernoulli outcome per packet, but the loss probability is not constant:
it rises with packet size (larger frames are more exposed to corruption) and differs by
medium. The right model is therefore logistic regression, which converts a bounded
probability into an unbounded linear predictor and yields odds ratios that network
engineers can quote directly. The case also shows why a marginal comparison (radio looks
twice as bad) must be checked against a conditional one (radio is worse *at the same size*),
and why rare events require care with confidence intervals.

## C. Dataset description

`packets.csv` has 1,000 rows.

| Column | Type | Description |
|---|---|---|
| `packet_id` | integer | 1–1,000 |
| `link` | text | `fibre` (639) or `radio` (361) |
| `size_bytes` | integer | Packet size, 200–9,000 bytes |
| `hour` | integer | Hour of transmission, 0–23 |
| `lost` | integer | 1 if lost, 0 if delivered |

**Generation method.** Packet sizes are lognormal (median ≈ 1,100 bytes, clipped to
200–9,000). Loss probability follows a logistic model:
\(\mathrm{logit}(p)=-4.2+0.00035\cdot\text{size}+0.8\cdot\mathbf{1}[\text{radio}]\), and
each packet is lost independently with that probability. The realised loss rate is 4.5 %
(45 packets), 2.97 % on fibre and 7.20 % on radio.

## D. Questions to investigate

1. What is the overall loss rate, with a confidence interval?
2. How does loss differ by link, and by packet size quartile?
3. Is the difference between links statistically significant?
4. How much does loss increase per additional 1,000 bytes?
5. After adjusting for packet size, what is the odds ratio for the radio link?
6. Are very small packets safe enough to promise 99 % delivery?
7. Does the hour of day matter?

## E. Relevant probability and statistical concepts

- Bernoulli trials and the binomial distribution.
- Conditional probability and marginal versus conditional comparisons.
- Odds, odds ratios and the logit link.
- Logistic regression: coefficients, standard errors, odds ratios, confidence intervals.
- Wald tests and the likelihood-ratio test.
- Confounding by a continuous covariate (packet size).
- Wilson intervals for small proportions.

## F. Mathematical formulation

Logistic model:

\[
\mathrm{logit}\,P(Y=1\mid x)=\ln\frac{p}{1-p}=\beta_0+\beta_1\,\text{size}
+\beta_2\,\mathbf{1}[\text{radio}].
\]

The odds ratio for a one-unit increase in \(x_j\) is \(e^{\beta_j}\); for a 1,000-byte increase
it is \(e^{1000\beta_1}\).

The probability at a given size and link is

\[
p(x)=\frac{1}{1+e^{-(\beta_0+\beta_1 x+\beta_2 r)}}.
\]

Wilson interval for a proportion \(\hat p=k/n\) uses the adjusted centre and width

\[
\tilde p=\frac{\hat p+\frac{z^2}{2n}}{1+\frac{z^2}{n}},\qquad
\text{half-width}=\frac{z}{1+\frac{z^2}{n}}\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}.
\]

## G. Step-by-step analytical approach

1. Compute the overall loss rate and a Wilson interval.
2. Compare loss by link (marginal) and by size quartile.
3. Check the size distribution by link — if radio packets are larger, the marginal
   comparison is confounded.
4. Fit the logistic model; report odds ratios with intervals.
5. Test the link effect with a likelihood-ratio test against a size-only model.
6. Predict the loss probability at 500 and 5,000 bytes on each link.
7. Check the hour-of-day effect and comment on multiplicity.
8. Write the service-level recommendation.

## I. Python practical implementation

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

packets = pd.read_csv("docs/data/case-studies/packets.csv")
print(packets.head(3).to_string(index=False))
print(f"packets: {len(packets)}, lost: {int(packets.lost.sum())} "
      f"({packets.lost.mean():.3%})")

print("\nby link:")
print(packets.groupby("link").agg(
    packets=("lost", "size"), lost=("lost", "sum"),
    loss_rate=("lost", "mean"),
    median_size=("size_bytes", "median")).round(4).to_string())

packets["size_q"] = pd.qcut(packets.size_bytes, 4, labels=["Q1", "Q2", "Q3", "Q4"])
print("\nloss by size quartile:")
print(packets.groupby("size_q", observed=True).agg(
    packets=("lost", "size"), loss_rate=("lost", "mean"),
    median_size=("size_bytes", "median")).round(4).to_string())

model = smf.logit("lost ~ size_bytes + C(link)", data=packets).fit(disp=0)
params = model.params
conf = model.conf_int()
odds = pd.DataFrame({
    "coef": params,
    "OR": np.exp(params),
    "OR_low": np.exp(conf[0]),
    "OR_high": np.exp(conf[1]),
    "p": model.pvalues,
}).round(4)
print("\nlogistic model:")
print(odds.to_string())
print(f"\nodds ratio per 1,000 bytes = {np.exp(params['size_bytes'] * 1000):.3f}")

size_only = smf.logit("lost ~ size_bytes", data=packets).fit(disp=0)
lr = 2 * (model.llf - size_only.llf)
from scipy import stats
print(f"likelihood-ratio test for link: LR = {lr:.2f}, "
      f"p = {stats.chi2.sf(lr, df=1):.4f}")

for size in (500, 5000):
    for link, flag in (("fibre", 0), ("radio", 1)):
        logit = params["Intercept"] + params["size_bytes"] * size + params["C(link)[T.radio]"] * flag
        print(f"predicted loss at {size} bytes on {link}: {1 / (1 + np.exp(-logit)):.3%}")
```

## K. Expected conclusions

- Overall loss 4.50 % (45 of 1,000); fibre 2.97 %, radio 7.20 %.
- Loss rises monotonically with size: 0.80 %, 3.59 %, 6.02 %, 7.60 % across quartiles
  (χ² = 15.4, df = 3, p = 0.0015).
- Radio packets are slightly larger (median 1,163 vs 1,054 bytes), so part of the marginal
  gap is a size effect; the adjusted model shows the link effect survives it.
- The logistic model gives an odds ratio of 1.451 per 1,000 bytes and 2.486 for radio
  (95 % CI about 1.35–4.58, p = 0.004): radio roughly doubles the odds of loss at the same
  size.
- Predicted loss at 500 bytes is 1.96 % on fibre and 4.74 % on radio; at 5,000 bytes it is
  9.67 % and 21.02 %.
- A 99 % delivery promise is not achievable at any packet size with the current base loss;
  even 98 % requires fibre packets below about 550 bytes, and radio cannot reach 98 % at
  any size.

## L. Detailed solution and discussion

**Step 1 — marginal rates.** Fibre loses 19 of 639 packets (2.97 %), radio loses 26 of 361
(7.20 %). The ratio is 2.4, and a two-proportion test gives z = 2.79, p = 0.005 — the
difference is real. A Wilson interval for radio's 7.20 % runs from 4.96 % to 10.34 %,
which is wide because only 361 packets were observed and losses are rare.

**Step 2 — the confounding check.** Radio packets are slightly larger (median 1,163 bytes
versus 1,054 on fibre), and loss rises with size, so part of the marginal gap could be a
size effect rather than a medium effect. The adjusted model is therefore essential: the
link odds ratio of 2.49 after controlling for size shows the gap is not explained by size
alone.

**Step 3 — the size gradient.** Loss by quartile is 0.80 %, 3.59 %, 6.02 % and 7.60 %,
with median sizes around 640, 1,100, 1,800 and 3,600 bytes. A chi-square of 15.4 on 3
degrees of freedom (p = 0.0015) rejects equal rates. The gradient is roughly linear on the
log-odds scale, which is what the logistic specification assumes.

**Step 4 — the model.** Coefficients: intercept −4.096, size 0.000372, radio 0.911. The
odds ratio per byte is 1.00037, so per 1,000 bytes it is \(e^{0.372} = 1.451\): a 1,000-byte
increase raises the odds of loss by 45 %. The radio odds ratio is \(e^{0.911} = 2.486\) with
a 95 % interval of 1.35 to 4.58. Both p-values are below 0.005.

**Step 5 — model comparison.** The likelihood-ratio statistic for adding link to a
size-only model is 8.6 on 1 degree of freedom, p ≈ 0.003. The link effect survives
adjustment, so the operator's complaint about the radio link is justified — but the size
effect is larger in practical terms: moving from a 500-byte to a 5,000-byte packet
multiplies the odds by \(e^{0.372 \times 4.5} ≈ 5.3\), more than the link's 2.5.

**Step 6 — prediction.** At 500 bytes: fibre logit = −4.096 + 0.186 = −3.910, loss 1.96 %;
radio adds 0.911, giving 4.74 %. At 5,000 bytes: fibre logit = −4.096 + 1.860 = −2.236,
loss 9.67 %; radio 21.02 %. Note how quickly the promises degrade: the same link that
delivers 98 % of 500-byte packets delivers only 79 % of 5,000-byte packets on radio.

**Step 7 — hour of day.** Loss does not depend on hour in the generator, and a quick check
shows no significant effect. If 24 hourly tests were run, roughly one would be significant
at 5 % by chance; the correct approach is a single test of hour as a categorical variable,
or a Bonferroni-corrected threshold of 0.05/24 ≈ 0.002.

**Service-level recommendation.** A 99 % delivery guarantee cannot be met at any packet
size with the current base loss: even 200-byte packets lose about 1.8 % on fibre and 4.3 %
on radio. For a 98 % guarantee, fibre packets must stay under about 550 bytes, and radio
cannot reach 98 % at any size. So the honest recommendation is to (i) reduce the baseline
loss — better hardware, forward error correction — and (ii) meanwhile segment traffic:
keep radio packets small and audio-only, and route bulk transfers over fibre. This turns a
model into an operational rule, which is what the network team needs.

**Caution on causality.** Link is not randomly assigned: traffic may be routed to radio
precisely when it is less reliable (bad weather, congestion). The odds ratio is a
conditional association, not the causal effect of switching medium, and the same caution
applies to every observational comparison in this course.
