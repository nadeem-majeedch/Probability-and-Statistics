## A. Problem statement

A public-health agency is considering population screening for a condition that affects
1 in 100 people. The test has sensitivity 0.90 and specificity 0.92, figures taken from a
laboratory validation study. An advocacy group argues that "a test that is right 90 % of
the time" justifies mass screening. The agency's statistician must estimate how many
positive results would be false, how the answer changes with prevalence, and what the
screening programme would cost in follow-up tests per case detected.

## B. Background and context

Bayes' theorem is the bridge between the laboratory and the clinic. Laboratory studies
report \(P(T^+\mid D)\); patients and policymakers need \(P(D\mid T^+)\). The two differ by
the base rate, and when the base rate is small the difference is dramatic. This case
makes the arithmetic concrete with a simulated cohort, then extends it to a
decision-analytic question: at what prevalence does screening become worthwhile, given
the cost and anxiety of false positives?

## C. Dataset description

`screening.csv` has 500 simulated patients with both the test result and the true disease
status.

| Column | Type | Description |
|---|---|---|
| `patient_id` | integer | Anonymous identifier |
| `age` | integer | Age 18–90, independent of disease in the simulation |
| `test_result` | text | `positive` / `negative` |
| `disease` | integer | 1 = disease present |

**Generation method.** Disease is Bernoulli(0.12); the test is positive with probability
0.90 when disease is present and 0.08 when it is absent. The sample therefore has a
realised prevalence of 13 %, higher than the 1 % population the agency cares about — a
reminder that a validation cohort is rarely representative of the screening population.

## D. Questions to investigate

1. Estimate sensitivity and specificity from the sample with confidence intervals.
2. Compute PPV and NPV at the sample prevalence of 13 %.
3. Apply Bayes' theorem at prevalences of 1 %, 5 %, 13 % and 30 %.
4. How many positive results are false at each prevalence, per 10,000 screened?
5. How many people must be screened to detect one true case at 1 % prevalence?
6. What follow-up test capacity would mass screening require?
7. At what prevalence does the PPV exceed 50 %?

## E. Relevant probability and statistical concepts

## F. Mathematical formulation

Law of total probability for a positive test:

\[
P(T^+)=P(T^+\mid D)P(D)+P(T^+\mid \bar D)P(\bar D)
=\mathrm{se}\cdot\pi+(1-\mathrm{sp})(1-\pi).
\]

Bayes' theorem:

\[
P(D\mid T^+)=\frac{\mathrm{se}\cdot\pi}{\mathrm{se}\cdot\pi+(1-\mathrm{sp})(1-\pi)}.
\]

The number of false positives per true positive is

\[
\frac{FP}{TP}=\frac{(1-\mathrm{sp})(1-\pi)}{\mathrm{se}\cdot\pi},
\]

and the number needed to screen to find one case is \(1/\pi\) (before test imperfection).

## I. Python practical implementation

```python
import numpy as np
import pandas as pd

screen = pd.read_csv("docs/data/case-studies/screening.csv")
tp = int(((screen.test_result == "positive") & (screen.disease == 1)).sum())
fp = int(((screen.test_result == "positive") & (screen.disease == 0)).sum())
fn = int(((screen.test_result == "negative") & (screen.disease == 1)).sum())
tn = int(((screen.test_result == "negative") & (screen.disease == 0)).sum())

se, sp = tp / (tp + fn), tn / (tn + fp)
pi_sample = (tp + fn) / len(screen)
print(f"TP={tp} FP={fp} FN={fn} TN={tn}")
print(f"sensitivity={se:.3f}  specificity={sp:.3f}  sample prevalence={pi_sample:.3f}")


def wilson(k, n, z=1.96):
    p = k / n
    denom = 1 + z**2 / n
    centre = (p + z**2 / (2 * n)) / denom
    half = z * np.sqrt(p * (1 - p) / n + z**2 / (4 * n**2)) / denom
    return centre - half, centre + half


print("95% CI sensitivity:", [round(v, 3) for v in wilson(tp, tp + fn)])
print("95% CI specificity:", [round(v, 3) for v in wilson(tn, tn + fp)])


def posterior(pi, se=se, sp=sp):
    return se * pi / (se * pi + (1 - sp) * (1 - pi))


print("\nprevalence | PPV  | NPV  | FP per TP | NNS (approx)")
for pi in (0.01, 0.05, 0.13, 0.30):
    ppv = posterior(pi)
    npv = (1 - pi) * sp / ((1 - pi) * sp + pi * (1 - se))
    fp_per_tp = (1 - sp) * (1 - pi) / (se * pi)
    nns = 1 / (se * pi)
    print(f"{pi:9.0%} | {ppv:.3f} | {npv:.3f} | {fp_per_tp:9.2f} | {nns:6.0f}")

per_10k = 10_000
cases = per_10k * 0.01
detected = per_10k * 0.01 * se
false_pos = per_10k * (1 - 0.01) * (1 - sp)
print(f"\nAt 1% prevalence, screening 10,000 people:")
print(f"  true cases {cases:.0f}, detected {detected:.0f}, missed {cases - detected:.0f}")
print(f"  false positives {false_pos:.0f}, total positives {detected + false_pos:.0f}")
print(f"  proportion of positives that are false: {false_pos / (detected + false_pos):.1%}")
```

## J. Visualization and interpretation

```python
import matplotlib.pyplot as plt

grid = np.linspace(0.001, 0.4, 300)
ppv = [posterior(p) for p in grid]
fpr_share = [(1 - sp) * (1 - p) / (se * p + (1 - sp) * (1 - p)) for p in grid]

fig, axes = plt.subplots(1, 2, figsize=(10, 3.8))
axes[0].plot(grid, ppv, color="#4c72b0")
axes[0].axhline(0.5, color="grey", ls="--", lw=1)
axes[0].axvline(0.01, color="crimson", ls=":", label="1% prevalence")
axes[0].set(title="Positive predictive value vs prevalence",
            xlabel="Prevalence", ylabel="P( disease | positive )")
axes[0].legend(frameon=False)

axes[1].plot(grid, fpr_share, color="#c44e52")
axes[1].set(title="Share of positives that are false",
            xlabel="Prevalence", ylabel="Proportion")
fig.tight_layout()
```

**How to read it.** Both curves are steep at low prevalence. At 1 % the PPV is about 12 %,
so 88 % of positives are false; by 13 % the PPV has climbed to 67 %, and above about 7 %
prevalence the PPV passes 50 %. The practical implication is that the same test
becomes a different clinical tool depending on who is tested, which is the entire argument
for targeted rather than mass screening.

## K. Expected conclusions

- Estimated sensitivity 0.908 (95 % CI ≈ 0.81–0.96), specificity 0.933 (0.90–0.95).
- At the sample prevalence of 13 %, PPV = 0.670.
- At 1 % prevalence, PPV falls to 0.120: 88 % of positives are false.
- At 5 % prevalence, PPV = 0.416; at 30 %, PPV = 0.853.
- Screening 10,000 people at 1 % prevalence yields about 91 true positives and 663 false
  positives — 7.3 false alarms per case found.
- About 110 people must be screened to detect one case at 1 % prevalence, so the
  follow-up burden is roughly 7.3 confirmatory tests per case.
- Mass screening is defensible only with a confirmatory second test and clear counselling
  about the meaning of a positive result.

## L. Detailed solution and discussion

**Step 1 — estimates.** From 65 diseased patients the test caught 59, giving sensitivity
0.908; from 435 healthy patients it correctly cleared 406, giving specificity 0.933. The
Wilson intervals (0.81–0.96 and 0.90–0.95) are wide enough that a laboratory would want a
larger validation sample before publishing them.

**Step 2 — the sample table.** PPV = 59/88 = 0.670 and NPV = 406/412 = 0.985. Note the
asymmetry: the test is far better at excluding disease than at confirming it, because
false positives outnumber false negatives five to one at this prevalence.

**Step 3 — Bayes at other prevalences.** With se = 0.908 and sp = 0.933, at π = 0.01 the
numerator is 0.00908 and the denominator 0.00908 + 0.0663 = 0.0754, so PPV = 0.120. At
π = 0.05: 0.0454/(0.0454 + 0.0637) = 0.416. At π = 0.30: 0.2724/(0.2724 + 0.0469) =
0.853. PPV rises steeply with prevalence. Setting se·π = (1 − sp)(1 − π) gives the 50 %
crossover at π = 0.067/(0.908 + 0.067) = 0.069, i.e. about 7 % prevalence.

**Step 4 — the 10,000-person calculation.** At 1 % prevalence there are 100 true cases, of
which 91 are detected and 9 missed. Of 9,900 healthy people, 663 test positive falsely.
Total positives: 754, of which 663 (88 %) are false. This is the number that decides
policy — not the 90 % sensitivity.

**Step 5 — the number needed to screen.** Detecting one case requires \(1/(\pi\cdot
\mathrm{se}) = 1/(0.01 \times 0.908) \approx 110\) people screened, and each detected case
brings about 7.3 false positives for follow-up. If the confirmatory test costs 40 units
and causes two weeks of anxiety, the programme's true cost per case is the confirmatory
work-up, not the initial test.

**Step 6 — the argument for targeted screening.** If the test is restricted to a
high-risk group with 20 % prevalence, PPV = 0.908 × 0.2/(0.908 × 0.2 + 0.067 × 0.8) =
0.772: almost four in five positives are genuine, and the false-positive burden falls by a
factor of six per case detected. This is why screening programmes use risk scores, age
criteria or family history to raise the prior before testing.

**Step 7 — limits of the analysis.** The sensitivity and specificity are assumed constant
across populations, which is often false: test performance varies with disease severity and
with the spectrum of patients in the validation study (spectrum bias). The simulation also
ignores imperfect gold standards, which bias both estimates. A real policy analysis would
add the cost of missed cases, the harms of treatment, and the uptake rate; the arithmetic
here is the necessary first step, not the whole decision.

**Why this matters beyond medicine.** The same structure governs fraud detection, spam
filtering, predictive policing and machine-learning alerts: when the event is rare, most
alarms are false even when the detector is good. That is why the ML case study A5 reports
precision and calibration, not only accuracy.
