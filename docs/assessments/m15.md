## Multiple-choice questions

```quiz
Q1. A p-value is
A) the probability of a Type II error
B) the probability the result will replicate
C) the probability that the null hypothesis is true
D) the probability of data at least as extreme as observed, assuming the null is true
* D
Why: The p-value is computed under the null and measures compatibility with it. It is not the probability of the null, nor a replication probability.

Q2. A Type I error occurs when
A) a true null hypothesis is rejected
B) a false null hypothesis is not rejected
C) the sample is too small
D) the test is two-sided
* A
Why: Rejecting a true null is a false positive, with probability \(\alpha\). Failing to reject a false null is a Type II error.

Q3. Power equals
A) \(1-\alpha\)
B) \(\alpha\)
C) \(1-\beta\)
D) \(\beta\)
* C
Why: Power is the probability of detecting a real effect, the complement of the Type II error rate. It depends on effect size, sample size, variability and \(\alpha\).

Q4. Holding everything else fixed, lowering \(\alpha\) from 0.05 to 0.01
A) increases power
B) decreases power
C) leaves power unchanged
D) eliminates bias
* B
Why: A stricter rejection threshold makes false positives rarer but real effects harder to detect, so \(\beta\) rises and power falls.

Q5. Power increases when
A) the sample size decreases
B) the effect size increases
C) the variability increases
D) the test becomes two-sided
* B
Why: Larger effects are easier to distinguish from noise. More data and lower variability also raise power; two-sided tests are slightly less powerful than one-sided ones.

Q6. A test gives \(p=0.03\) at \(\alpha=0.05\). The correct conclusion is
A) the null is true
B) reject the null
C) accept the alternative with 97 % certainty
D) the effect is large
* B
Why: \(p<\alpha\) is the rejection rule. It does not establish the null's falsity with a stated probability, nor the size or importance of the effect.

Q7. \(p=0.20\) means
A) the effect is zero
B) the null is proven
C) insufficient evidence against the null
D) the alternative is false
* C
Why: A large p-value means the data are compatible with the null; it does not prove it. The interval may still include meaningful effects.

Q8. A two-sided test is appropriate when
A) the data are normal
B) only an increase matters
C) either direction of departure matters
D) the sample is large
* C
Why: Two-sided testing doubles the tail area but detects departures in both directions. Use one-sided only when a departure in the other direction would be ignored entirely, decided in advance.

Q9. The one-sample \(t\)-test assumes
A) the variance is known
B) the data are categorical
C) the sample is paired
D) the population is normal or \(n\) is large enough for the CLT
* D
Why: The statistic's null distribution is \(t\) when the data are normal; for large \(n\) the CLT makes it approximately valid. The variance need not be known — that is why \(t\) is used.

Q10. Testing 20 independent hypotheses at \(\alpha=0.05\) each, the probability of at least one
A) 0.20
B) 0.95
C) 0.05
D) 0.64
* D
Why: \(1-0.95^{20}=1-0.358=0.642\). Multiplicity inflates false positives, which is why Bonferroni or FDR control is needed.

Q11. A result is statistically significant but the effect is tiny. The correct reading is
A) the effect is precisely estimated but may be practically irrelevant
B) the test is invalid
C) the sample was too small
D) the effect is important
* A
Why: Significance addresses whether an effect differs from zero, not whether it matters. With large samples, trivial effects become significant; effect size and interval width carry the practical meaning.

Q12. A paired test is preferred to an independent two-sample test when
A) variances are equal
B) the outcome is binary
C) observations come in matched pairs
D) the sample is large
* C
Why: Pairing removes between-pair variability, increasing power. Analysing paired data as independent throws away that advantage and misstates the standard error.

Q13. A 95 % confidence interval for a difference excludes zero. The corresponding two-sided test
A) require a larger sample
B) reject the null
C) fail to reject the null
D) have an inconclusive result
* B
Why: The interval and the test are dual: excluding zero is equivalent to \(p<0.05\) for the same two-sided hypothesis. This is a quick consistency check.

Q14. The test statistic for a sample mean with known variance is
A) \((\bar x-\mu_0)/(\sigma/\sqrt n)\)
B) \((\bar x-\mu_0)/\sigma\)
C) \((\bar x-\mu_0)\sqrt n\)
D) \((\bar x-\mu_0)/(s/n)\)
* A
Why: The observed deviation is scaled by the standard error of the mean. Omitting \(\sqrt n\) treats the mean as a single observation.

Q15. Comparing two independent proportions with small counts, the most appropriate test is
A) Fisher's exact test
B) a paired \(t\)-test
C) a chi-square test of variance
D) a \(z\)-test for proportions using the normal approximation
* A
Why: The normal approximation fails when expected counts are small, so an exact test is needed. Large samples make the \(z\) or chi-square approximation adequate.
```

## Conceptual short questions

**S1.** Explain the difference between a Type I and a Type II error with a screening example.

<details><summary>Model answer</summary>
A Type I error is a false alarm — flagging a healthy patient as diseased (\(\alpha\)). A Type II
error is a missed case — declaring a diseased patient healthy (\(\beta\)). Lowering the false-alarm
rate by requiring stronger evidence raises the miss rate, which is why the threshold depends on
the relative costs.
</details>

**S2.** Why can a p-value not be interpreted as the probability that the null hypothesis is true?

<details><summary>Model answer</summary>
The p-value is \(P(\text{data}\mid H_0)\), while \(P(H_0\mid\text{data})\) needs a prior over
hypotheses and Bayes' theorem. Small p-values are common when testing many hypotheses even if all
nulls are true, so the two quantities can differ dramatically.
</details>

**S3.** What determines the power of a test, and how would you increase it in practice?

<details><summary>Model answer</summary>
Power rises with larger effect size, larger \(n\), smaller variability (better measurement or
paired designs), and a more liberal \(\alpha\). In practice, increase the sample, reduce noise by
design, or use a more sensitive test; do not raise \(\alpha\) without considering the cost of
false positives.
</details>

**S4.** Why does multiple testing inflate the false-positive rate, and what are two remedies?

<details><summary>Model answer</summary>
Each test has a 5 % chance of a false positive; with \(m\) tests the chance that at least one
fires grows toward 1. Bonferroni controls the family-wise error by testing at \(\alpha/m\), and
Benjamini–Hochberg controls the false discovery rate, which is less conservative when many
hypotheses are tested.
</details>

**S5.** What is the difference between statistical and practical significance?

<details><summary>Model answer</summary>
Statistical significance says the observed effect is unlikely under the null; practical
significance says the effect is large enough to matter. With large samples, trivially small
effects become significant, so report effect sizes and confidence intervals alongside p-values.
</details>

**S6.** Explain the duality between a confidence interval and a hypothesis test.

<details><summary>Model answer</summary>
A \(100(1-\alpha)\)% interval contains exactly the parameter values not rejected by a two-sided
test at level \(\alpha\). So an interval excluding \(\mu_0\) corresponds to \(p<\alpha\). The
interval is more informative because it shows the range of plausible values.
</details>

**S7.** Why is a one-sided test sometimes criticised?

<details><summary>Model answer</summary>
Because the direction must be specified before seeing the data; choosing it afterwards to halve
the p-value is a form of p-hacking. One-sided tests are legitimate when effects in the other
direction are genuinely irrelevant, and this should be justified in advance.
</details>

**S8.** What does it mean that a test is "consistent"?

<details><summary>Model answer</summary>
Power tends to 1 as \(n\to\infty\) for any fixed non-zero effect. Consistency means sufficiently
large studies will detect a real effect, but it says nothing about small samples or about effects
too small to matter.
</details>

**S9.** Why should you report an effect size and interval rather than only a p-value?

<details><summary>Model answer</summary>
The p-value conflates effect size, variability and sample size, so it cannot tell you how large
or important the effect is. The estimate and interval give the magnitude and precision, enabling
readers to judge practical relevance and to combine results in meta-analysis.
</details>

**S10.** A test's assumptions are violated. What are your options?

<details><summary>Model answer</summary>
Use a method robust to the violation (Welch's \(t\) instead of pooled, bootstrap, rank-based
tests), transform the data, or model the structure explicitly (mixed models for clustering).
Check sensitivity of conclusions across approaches rather than silently ignoring the problem.
</details>

## Numerical problems

**N1.** A sample of 36 has mean 52, \(\sigma=12\), testing \(H_0:\mu=50\). Compute the
\(z\)-statistic and the two-sided p-value.

<details><summary>Worked solution</summary>
\(\mathrm{SE}=12/6=2\); \(z=(52-50)/2=1.0\). Two-sided p \(=2(1-\Phi(1))=2(0.1587)=0.317\).
No evidence against \(\mu=50\).
</details>

**N2.** For \(z=2.10\), find the two-sided p-value.

<details><summary>Worked solution</summary>
One tail \(=1-\Phi(2.10)=0.0179\), so two-sided p \(=0.0357\). This is below 0.05, so the null
would be rejected at the 5 % level.
</details>

**N3.** A sample of 16 has mean 10.5 and \(s=2\), testing \(\mu=10\). Compute the \(t\)-statistic.

<details><summary>Worked solution</summary>
\(\mathrm{SE}=2/4=0.5\); \(t=(10.5-10)/0.5=1.0\) with 15 df. The two-sided p-value is about
0.33 — the sample is too small to distinguish this from noise at 5 %.
</details>

**N4.** You test 20 hypotheses at \(\alpha=0.05\). Using Bonferroni, what threshold should each
test use?

<details><summary>Worked solution</summary>
\(\alpha/m=0.05/20=0.0025\). A result with \(p=0.01\) would be significant unadjusted but not
after correction.
</details>

**N5.** A two-sided test at \(\alpha=0.05\) has power 0.80 for a given effect. What is \(\beta\),
and what happens to power if the sample doubles?

<details><summary>Worked solution</summary>
\(\beta=1-0.80=0.20\). Doubling \(n\) reduces the standard error by \(\sqrt2\), increasing
power (roughly to 0.95–0.97 for the same effect). Exact values require a power calculation.
</details>

**N6.** In a one-sample test, \(n=25\), \(s=10\), \(\bar x=105\), \(\mu_0=100\). Compute the
95 % interval and state whether \(\mu_0\) lies inside.

<details><summary>Worked solution</summary>
\(\mathrm{SE}=2\); \(t_{0.975,24}=2.064\); margin \(=4.13\); interval \(100.87\) to \(109.13\).
The value 100 lies outside, so the two-sided test rejects at 5 % (\(t=2.5\), p ≈ 0.02).
</details>

**N7.** Two proportions: 40/200 and 55/200. Compute the pooled proportion and the standard error
of the difference.

<details><summary>Worked solution</summary>
Pooled \(\hat p=95/400=0.2375\);
\(\mathrm{SE}=\sqrt{0.2375(0.7625)(1/200+1/200)}=\sqrt{0.1811\times0.01}=0.04255\).
Difference \(=-0.075\), \(z=-1.76\), p ≈ 0.078.
</details>

**N8.** A test rejects at \(\alpha=0.05\) with \(p=0.04\). If the same data were tested at
\(\alpha=0.01\), what would the decision be?

<details><summary>Worked solution</summary>
Fail to reject, since \(0.04>0.01\). The decision depends on the pre-specified \(\alpha\), which
is why it must be chosen before analysis. The three-decimal p-value should be reported regardless.
</details>

**N9.** For a two-sided test with \(z=1.96\) exactly, what is the p-value, and what decision
follows at 5 %?

<details><summary>Worked solution</summary>
p \(=2(1-0.975)=0.05\). At \(\alpha=0.05\) this is the boundary; conventionally, reject when
\(p\le\alpha\), so the decision is exactly at the threshold — a reminder that 0.05 is a
convention, not a natural boundary.
</details>

**N10.** A study with 400 observations finds a difference of 0.5 units with \(\mathrm{SE}=0.2\).
Compute the test statistic, p-value and 95 % interval.

<details><summary>Worked solution</summary>
\(z=0.5/0.2=2.5\), two-sided p \(=0.0124\); interval \(0.5\pm1.96(0.2)=0.108\) to
\(0.892\). The effect is significant and the interval excludes zero, but its width shows the
effect could be small.
</details>

## Scenario problems

**P1.** An A/B test yields conversion 3.1 % versus 3.6 % with 20,000 users per arm. Compute an
approximate test and decide, then discuss what the decision means commercially.

<details><summary>Outline answer</summary>
\(\mathrm{SE}=\sqrt{0.031(0.969)/20{,}000+0.036(0.964)/20{,}000}\approx0.00182\);
\(z=0.005/0.00182=2.75\), p ≈ 0.006. Significant at 5 %. Commercially, a 0.5-point lift is about
16 % relative improvement; evaluate it against implementation cost, and check guardrail metrics
and novelty effects before shipping.
</details>

**P2.** A team runs 50 tests on a dashboard and highlights the three with \(p<0.05\). What is
wrong, and what would you advise?

<details><summary>Outline answer</summary>
Under the null, about 2.5 of 50 tests would be "significant" by chance, so the three are
indistinguishable from noise. Apply a multiplicity correction (Bonferroni or FDR), pre-register
hypotheses, and treat exploratory findings as hypotheses for confirmation on fresh data.
</details>

**P3.** A drug trial fails to reach \(p<0.05\) but the 95 % interval for the effect is (−1 %, 12 %).
A newspaper reports "drug does not work". Evaluate.

<details><summary>Outline answer</summary>
The study is inconclusive, not negative: the interval includes a clinically meaningful 12 %
benefit. "Absence of evidence is not evidence of absence." Report the interval and the study's
power; a larger trial may be warranted.
</details>

**P4.** You must choose between a \(t\)-test and a Mann–Whitney test for skewed cost data with
outliers. How do you decide?

<details><summary>Outline answer</summary>
The \(t\)-test compares means and is sensitive to skew and outliers, though it is robust for large
\(n\); Mann–Whitney compares distributions (stochastic dominance) and is robust but answers a
different question. Decide which quantity matters — total cost (mean) or typical patient
(median/rank) — and report both if they disagree.
</details>

**P5.** A quality engineer runs a two-sided test each hour and stops the line when \(p<0.05\).
After a week, the line was stopped 10 times with no real problems. Explain.

<details><summary>Outline answer</summary>
About 5 % of 168 hourly tests is roughly 8 false alarms, so 10 stops is consistent with a stable
process. Repeated testing without adjustment guarantees false alarms. Use control charts with
limits set for the desired false-alarm rate, or adjust for multiplicity.
</details>

## Challenging analytical problems

**C1.** Show that the two-sided \(z\)-test and the 95 % confidence interval give the same decision.

<details><summary>Derivation</summary>
Reject \(H_0:\mu=\mu_0\) when \(|(\bar x-\mu_0)/(\sigma/\sqrt n)|>1.96\), i.e. when
\(\mu_0\) lies outside \(\bar x\pm1.96\sigma/\sqrt n\), which is exactly the 95 % interval.
The equivalence holds for any \(\alpha\) with the corresponding critical value.
</details>

**C2.** Derive the relationship between sample size and power for a one-sample \(z\)-test, and use
it to explain why doubling power is expensive.

<details><summary>Derivation</summary>
Power \(=P(|Z+\delta|>z_{\alpha/2})\) where \(\delta=(\mu_1-\mu_0)\sqrt n/\sigma\) is the
non-centrality. For a fixed effect and \(\alpha\), power depends on \(\delta\), so
\(n\propto(z_{\alpha/2}+z_\beta)^2\sigma^2/(\mu_1-\mu_0)^2\). Because \(n\) scales with the
square of the sum of critical values, moving power from 0.80 to 0.90 requires substantially more
than a proportional increase in sample size.
</details>

**C3.** Explain why \(p\)-values are uniformly distributed under the null, and use this to derive
the family-wise error rate for \(m\) independent tests.

<details><summary>Derivation</summary>
Under \(H_0\) the test statistic has a continuous null distribution, so \(P(p\le t)=t\) for
\(t\in[0,1]\) — uniformity. Independence then gives
\(P(\text{no rejection among }m)=(1-\alpha)^m\), so the family-wise error rate is
\(1-(1-\alpha)^m\approx m\alpha\) for small \(\alpha\). Setting \(1-(1-\alpha')^m=0.05\) yields the
Šidák threshold; Bonferroni's \(\alpha/m\) is a slightly conservative approximation.
</details>
