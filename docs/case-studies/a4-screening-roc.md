## A. Problem statement

A laboratory has a binary screening test and wants to replace it with a graded assay that
returns a continuous score. Before switching, the medical director needs to know how well
the graded score discriminates, what threshold to use, how sensitivity and specificity
trade off at each cut-off, and how the choice should depend on the relative cost of a
missed case versus a false alarm.

## B. Background and context

ROC analysis is the standard language for comparing diagnostic tests. It plots the
true-positive rate against the false-positive rate as the threshold moves, and its area
summarises discrimination independently of any particular cut-off. What ROC cannot do is
choose the threshold: that is a decision problem requiring costs, prevalence and the harm
of each error type. This case connects the two, and shows why "the test with the highest
AUC" is not automatically the right test for a screening programme.

## C. Dataset description

\[
\text{score}_i = 3.0\cdot\mathbf{1}[\text{positive}]_i+\varepsilon_i,\qquad

\]

with a fixed seed, representing a continuous assay that is informative but noisy. The score
is a teaching artefact: it is derived from the test result, not an independent measurement.

## E. Relevant probability and statistical concepts

- Sensitivity, specificity, and the ROC space.
- AUC as the probability of correct ranking of a random positive–negative pair.
- Threshold selection: Youden's index, cost-weighted expected loss.
- The trade-off between sensitivity and specificity is unavoidable.
- PPV and prevalence: the same threshold behaves differently in different populations.
- Bootstrapping the AUC for a confidence interval.
- The difference between discrimination and calibration.

## F. Mathematical formulation

For threshold \(c\), define \(\hat y_i=\mathbf{1}[\text{score}_i>c]\). Then

\[
\mathrm{TPR}(c)=P(\hat y=1\mid D=1),\qquad
\mathrm{FPR}(c)=P(\hat y=1\mid D=0).
\]

The ROC curve traces \((\mathrm{FPR}(c),\mathrm{TPR}(c))\) as \(c\) varies, and

\[
\mathrm{AUC}=\int_0^1 \mathrm{TPR}\,d(\mathrm{FPR})
=P(\text{score}_D>\text{score}_{\bar D}).
\]

Youden's index is \(J(c)=\mathrm{TPR}(c)+\mathrm{TNR}(c)-1\); the cost-minimising threshold
minimises

\[
C_{\text{tot}}(c)=C_{FN}\cdot FN(c)+C_{FP}\cdot FP(c).
\]

With prevalence \(\pi\), the posterior odds form of the optimal cut-off satisfies

\[
\frac{p(c\mid D)}{p(c\mid \bar D)}>\frac{C_{FP}}{C_{FN}}\cdot\frac{1-\pi}{\pi}.
\]

## I. Python practical implementation

```python
import numpy as np
import pandas as pd
from scipy import stats
from sklearn.metrics import roc_auc_score, roc_curve

screen = pd.read_csv("docs/data/case-studies/screening.csv")
disease = screen.disease.values
binary = (screen.test_result == "positive").astype(int).values

tp = int(((binary == 1) & (disease == 1)).sum())
fp = int(((binary == 1) & (disease == 0)).sum())
fn = int(((binary == 0) & (disease == 1)).sum())
tn = int(((binary == 0) & (disease == 0)).sum())
se, sp = tp / (tp + fn), tn / (tn + fp)
print(f"binary test: TP={tp} FP={fp} FN={fn} TN={tn}")
print(f"sensitivity={se:.3f}, specificity={sp:.3f}, "
      f"AUC={(se + sp) / 2:.3f} (equals (se+sp)/2 for a single cut-off)")

# Graded score representing a continuous assay (fixed seed, documented in the dataset notes)
rng = np.random.default_rng(7)
score = 3.0 * binary + rng.normal(0, 1, len(screen))
print(f"\ngraded score AUC = {roc_auc_score(disease, score):.3f}")

print("\nthreshold table:")
print(f"{'cut':>6} {'sens':>6} {'spec':>6} {'PPV':>6} {'Youden':>7}")
for cut in (-0.5, 0.0, 0.5, 1.5, 2.5):
    predicted = score > cut
    t = int((predicted & (disease == 1)).sum())
    f = int((predicted & (disease == 0)).sum())
    n_ = int((~predicted & (disease == 1)).sum())
    m = int((~predicted & (disease == 0)).sum())
    sens, spec = t / (t + n_), m / (m + f)
    ppv = t / max(1, t + f)
    print(f"{cut:6.1f} {sens:6.3f} {spec:6.3f} {ppv:6.3f} {sens + spec - 1:7.3f}")

cutoffs = np.linspace(score.min(), score.max(), 200)
cost_fn, cost_fp = 50, 1
costs = []
for cut in cutoffs:
    predicted = score > cut
    n_ = int((~predicted & (disease == 1)).sum())
    f = int((predicted & (disease == 0)).sum())
    costs.append(cost_fn * n_ + cost_fp * f)
best = cutoffs[int(np.argmin(costs))]
print(f"\ncost-minimising cut-off (FN=50, FP=1): {best:.3f} "
      f"with expected cost {min(costs)}")

fpr, tpr, thresholds = roc_curve(disease, score)
youden = tpr - fpr
best_youden = thresholds[int(np.argmax(youden))]
print(f"Youden-optimal cut-off: {best_youden:.3f}")

rng_boot = np.random.default_rng(11)
aucs = []
for _ in range(500):
    idx = rng_boot.integers(0, len(disease), len(disease))
    if len(np.unique(disease[idx])) == 2:
        aucs.append(roc_auc_score(disease[idx], score[idx]))
print(f"bootstrap 95% CI for AUC: "
      f"[{np.percentile(aucs, 2.5):.3f}, {np.percentile(aucs, 97.5):.3f}]")
```

## J. Visualization and interpretation

```python
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(10, 3.9))
axes[0].plot(fpr, tpr, color="#4c72b0",
             label=f"graded score (AUC {roc_auc_score(disease, score):.3f})")
axes[0].plot([0, 1], [0, 1], color="grey", ls="--", label="chance")
axes[0].scatter([1 - sp], [se], color="crimson", zorder=5, label="binary test")
axes[0].set(title="ROC curve", xlabel="False positive rate", ylabel="True positive rate")
axes[0].legend(frameon=False, fontsize=8)

prevalences = np.array([0.01, 0.05, 0.13, 0.30])
sens_at_best = tpr[int(np.argmax(youden))]
spec_at_best = 1 - fpr[int(np.argmax(youden))]
ppvs = [(sens_at_best * p) / (sens_at_best * p + (1 - spec_at_best) * (1 - p))
        for p in prevalences]
axes[1].plot(prevalences * 100, ppvs, marker="o", color="#c44e52")
axes[1].set(title="PPV at the Youden threshold", xlabel="Prevalence (%)",
            ylabel="PPV")
fig.tight_layout()
```

**How to read it.** The ROC curve rises steeply then flattens, with an area of 0.91. The
binary test sits as a single point on (or just above) the curve: thresholding collapses the
score into one operating point, and here the binary test's point is slightly better than the
curve at that false-positive rate, which is why its AUC is marginally higher. The right
panel is the sobering one: at the Youden threshold, a 1 % prevalence gives a PPV below 10 %,
so most positives would be false.

## K. Expected conclusions

- The binary test has sensitivity 0.908, specificity 0.933 and AUC 0.921.
- The graded score has AUC 0.907 (bootstrap 95 % CI 0.859–0.950) — slightly *lower* than the
  binary test, because adding noise to a thresholded result destroys information.
- Threshold table (score > cut): at −0.5 sensitivity 0.954, specificity 0.317, PPV 0.173; at
  0.0: 0.954, 0.513, 0.226; at 0.5: 0.954, 0.687, 0.313; at 1.5: 0.862, 0.894, 0.549; at 2.5:
  0.600, 0.952, 0.650.
- Youden's index peaks at cut ≈ 1.67 with J = 0.779 (sensitivity 0.862, specificity 0.917).
- With \(C_{FN}=50\) and \(C_{FP}=1\), the cost-minimising cut drops to 0.80 (sensitivity 0.954,
  specificity 0.770, 3 missed cases, 100 false positives).
- At 1 % prevalence that low threshold yields a PPV of 0.095, so a positive score must be
  confirmed by a second test before treatment; at 30 % prevalence the same threshold gives
  PPV 0.817.
- The recommended policy is a two-stage pathway: a sensitive first threshold, then a
  specific confirmatory assay.

## L. Detailed solution and discussion

**Step 1 — the binary test.** Sensitivity 0.908, specificity 0.933. Its AUC, 0.920, is
exactly the average of the two — a mathematical identity for a test with a single cut-off,
because the ROC "curve" has one interior point. This is why AUC is uninformative when
comparing thresholded tests: it is a monotone transformation of the operating point.

**Step 2 — the graded score.** AUC 0.907 (bootstrap 95 % CI 0.859–0.950), marginally *below*
the binary test's 0.921. This is an honest and instructive result: the score was built by
adding normal noise to the binary result, so it cannot contain more information than the
binary test — it only spreads that information over a continuum. A genuine continuous assay,
measured independently of the binary cut-off, is what would raise discrimination; a noisy
re-encoding of a thresholded variable does not.

**Step 3 — the threshold table.** Moving the cut from −0.5 to 2.5 trades sensitivity for
specificity: 0.954 → 0.600 for sensitivity, 0.317 → 0.952 for specificity. PPV rises from
0.173 to 0.650 as the threshold gets stricter, because fewer healthy people cross it. Note
that sensitivity is flat at 0.954 across cuts below 0.5: every positive test clears those
thresholds, so lowering the cut further only adds false positives. No threshold is
"correct" without a statement of costs.

**Step 4 — Youden.** Maximising sensitivity + specificity − 1 puts the optimum at cut 1.67,
where sensitivity is 0.862 and specificity 0.917 (J = 0.779). Youden's index implicitly
weights the two error types equally, which is rarely right in medicine: a missed case is
usually far worse than a false alarm.

**Step 5 — cost-based threshold.** With \(C_{FN}=50\) and \(C_{FP}=1\), the expected cost is
\(50\cdot FN+FP\), and the optimum moves down to 0.80, where sensitivity is 0.954 and
specificity 0.770. Per 500 patients that is 3 missed cases and 100 false positives, for a
total expected cost of 250 — much better than the 426 of the all-flag policy and clearly
better than Youden's operating point on this cost function.

**Step 6 — prevalence.** The cost-optimal threshold on the probability scale depends on
prevalence: with rarer disease, the same score is less likely to be a true positive, so a
higher cut is needed to keep PPV acceptable, or a confirmatory test must follow. At 1 %
prevalence the Youden threshold gives PPV 0.095; at 30 %, the same threshold gives PPV
0.817. The threshold and the population cannot be chosen independently.

**Step 7 — recommendation.** Use the graded assay with a low first-stage cut (near 0.0) to
maximise detection, and confirm every positive with a specific second test. This two-stage
design keeps sensitivity high, controls the false-positive burden on the confirmatory
service, and makes PPV a property of the pathway rather than of a single number.

**What ROC cannot tell you.** It ignores prevalence, costs, and the consequences of the
confirmatory pathway. A test with AUC 0.96 can still be a bad screening tool if the disease
is rare and the confirmatory test is invasive. The decision-analytic layer — expected cost,
harm, capacity — is what turns a curve into a policy.
