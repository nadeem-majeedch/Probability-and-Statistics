## A. Problem statement

A hospital laboratory evaluates a new screening test for a chronic condition. In a sample
of 500 patients the test result and the true disease status are both recorded. The
laboratory director asks: how accurate is the test, what does a positive result mean for
a patient, and how should the result be explained to someone who is anxious?

## B. Background and context

Diagnostic accuracy is the cleanest place to learn conditional probability, because the
four quantities that matter are all conditional probabilities and they are routinely
confused with one another. Sensitivity — the probability of a positive test given
disease — is not the probability of disease given a positive test. Confusing them is the
"prosecutor's fallacy" of clinical practice, and it produces exactly the wrong counselling
for patients: a "90 % accurate" test can still mean that most positives are false when the
condition is rare. Hospitals, screening programmes and public-health agencies live with
this arithmetic every day.

## C. Dataset description

`screening.csv` has 500 rows and four columns.

## E. Relevant probability and statistical concepts

- Events, complements, joint and conditional probability.
- Sensitivity (true-positive rate) and specificity (true-negative rate).
- Positive and negative predictive value.
- Bayes' theorem and base rates.
- Contingency tables, marginal versus conditional proportions.
- Sampling variability of proportions; confidence intervals for a proportion.

## F. Mathematical formulation

With \(D\) = disease, \(T^+\) = positive test:

\[
\text{sensitivity}=P(T^+\mid D)=\frac{TP}{TP+FN},\qquad
\text{specificity}=P(T^-\mid \bar D)=\frac{TN}{TN+FP}.
\]

Predictive values reverse the conditioning:

\[
PPV=P(D\mid T^+)=\frac{TP}{TP+FP},\qquad
NPV=P(\bar D\mid T^-)=\frac{TN}{TN+FN}.
\]

Bayes' theorem connects them through prevalence \(\pi=P(D)\):

\[
P(D\mid T^+)=\frac{\pi\,\mathrm{se}}{\pi\,\mathrm{se}+(1-\pi)(1-\mathrm{sp})}.
\]

Accuracy \(=(TP+TN)/n\) mixes the two error types and depends on prevalence, which is why
it is a poor summary: a test that always says "negative" achieves 87 % accuracy at 13 %
prevalence while missing every case.

## G. Step-by-step analytical approach

3. Compute the false-negative rate and the false-positive rate.
4. Recompute the PPV by Bayes' theorem and check it matches the table.
5. Plot PPV against prevalence for the estimated sensitivity and specificity.

## I. Python practical implementation

```python
import numpy as np
import pandas as pd
from scipy import stats

screen = pd.read_csv("docs/data/case-studies/screening.csv")
print(screen.head(3).to_string(index=False))
print("rows:", len(screen), "| prevalence:", round(screen.disease.mean(), 4))

table = pd.crosstab(screen.test_result, screen.disease, margins=True)
print("\nconfusion matrix (rows = test, columns = disease):")
print(table.to_string())

tp = int(((screen.test_result == "positive") & (screen.disease == 1)).sum())
fp = int(((screen.test_result == "positive") & (screen.disease == 0)).sum())
fn = int(((screen.test_result == "negative") & (screen.disease == 1)).sum())
tn = int(((screen.test_result == "negative") & (screen.disease == 0)).sum())

sensitivity = tp / (tp + fn)
specificity = tn / (tn + fp)
ppv = tp / (tp + fp)
npv = tn / (tn + fn)
accuracy = (tp + tn) / len(screen)
prevalence = screen.disease.mean()

print(f"\nTP={tp} FP={fp} FN={fn} TN={tn}")
print(f"sensitivity = {sensitivity:.3f}  specificity = {specificity:.3f}")
print(f"PPV = {ppv:.3f}  NPV = {npv:.3f}  accuracy = {accuracy:.3f}")
print(f"false negative rate = {1 - sensitivity:.3f}  false positive rate = {1 - specificity:.3f}")


def bayes_ppv(pi, se=sensitivity, sp=specificity):
    return pi * se / (pi * se + (1 - pi) * (1 - sp))


print("\nPPV by prevalence:")
for pi in (0.01, 0.05, 0.13, 0.30):
    print(f"  prevalence {pi:5.0%} -> PPV {bayes_ppv(pi):.3f}")

# Wilson intervals (better than normal approximation for proportions near 0 or 1)
def wilson(k, n, z=1.96):
    p = k / n
    denom = 1 + z**2 / n
    centre = (p + z**2 / (2 * n)) / denom
    half = z * np.sqrt(p * (1 - p) / n + z**2 / (4 * n**2)) / denom
    return centre - half, centre + half


print("\n95% Wilson CI sensitivity:", [round(v, 3) for v in wilson(tp, tp + fn)])
print("95% Wilson CI specificity:", [round(v, 3) for v in wilson(tn, tn + fp)])
print("95% Wilson CI PPV:", [round(v, 3) for v in wilson(tp, tp + fp)])
```

## J. Visualization and interpretation

```python
import matplotlib.pyplot as plt

prevalences = np.linspace(0.001, 0.5, 200)
ppv_curve = [bayes_ppv(p) for p in prevalences]
npv_curve = [(1 - p) * specificity / ((1 - p) * specificity + p * (1 - sensitivity))
             for p in prevalences]

fig, axes = plt.subplots(1, 2, figsize=(10, 3.6))
axes[0].imshow([[tn, fp], [fn, tp]], cmap="Blues")
axes[0].set(xticks=[0, 1], xticklabels=["healthy", "diseased"],
            yticks=[0, 1], yticklabels=["negative", "positive"],
            title="Confusion matrix")
for (i, j), value in {(0, 0): tn, (0, 1): fp, (1, 0): fn, (1, 1): tp}.items():
    axes[0].text(j, i, value, ha="center", va="center", color="black", fontsize=13)
axes[1].plot(prevalences, ppv_curve, label="PPV")
axes[1].plot(prevalences, npv_curve, ls="--", label="NPV")
axes[1].axvline(prevalence, color="grey", ls=":", label="sample prevalence")
axes[1].set(title="Predictive values vs prevalence", xlabel="Prevalence",
            ylabel="Probability", ylim=(0, 1))
axes[1].legend(frameon=False)
fig.tight_layout()
```

**How to read it.** The confusion matrix shows the asymmetry: 29 false positives against
6 false negatives. The test is good at ruling the disease out (NPV 0.985) and only
moderate at confirming it (PPV 0.670) at this prevalence. The right-hand panel is the
crucial picture: as prevalence falls, PPV collapses while NPV rises. At 1 % prevalence
the same test produces a positive result that is correct only about 12 % of the time.

## K. Expected conclusions

- The sample contains 65 diseased and 435 healthy patients (13 % prevalence).
- Sensitivity = 59/65 = 0.908; specificity = 406/435 = 0.933.
- PPV = 59/88 = 0.670; NPV = 406/412 = 0.985; accuracy = 465/500 = 0.930.
- Overall accuracy of 93 % sounds excellent, but it is inflated by the low prevalence:
  the same test at 1 % prevalence would have a PPV of 0.12.
- A positive result is therefore "probably true but requires confirmation", not a
  diagnosis; a negative result is strong evidence of absence.
- The test is much better at excluding disease than at confirming it.

## L. Detailed solution and discussion

**Step 1 — the table.** Positive tests: 88, of which 59 truly diseased and 29 healthy.
Negative tests: 412, of which 406 truly healthy and 6 diseased. The imbalance in the
margins (65 diseased versus 435 healthy) is what creates the predictive-value asymmetry.

**Step 2 — accuracy measures.** Sensitivity 0.908: the test misses 9.2 % of cases (6 of
65). Specificity 0.933: it falsely alarms 6.7 % of healthy patients (29 of 435). PPV
0.670: two-thirds of positives are genuine. NPV 0.985: a negative is very reassuring,
with a 1.5 % chance of a missed case.

**Step 3 — Bayes check.** Using π = 0.13, se = 0.908, sp = 0.933:
0.13 × 0.908 = 0.1180; (1 − 0.13) × 0.067 = 0.0583; PPV = 0.1180/0.1763 = 0.669,
matching the table's 0.670 up to rounding (the table uses the realised counts 59/88).

**Step 4 — prevalence dependence.** At 1 % prevalence the numerator is 0.00908 and the
denominator 0.00908 + 0.0663 = 0.0754, giving PPV = 0.120. At 5 %: 0.0454/(0.0454 +
0.0637) = 0.416. At 13 %: 0.670. The message: predictive value is a property of the test
*and the population*, not of the test alone. This is why screening programmes targeted at
high-risk groups obtain far more informative positives than mass screening.

**Step 5 — uncertainty.** Wilson 95 % intervals are roughly 0.81–0.96 for sensitivity,
0.90–0.95 for specificity and 0.57–0.76 for PPV. The PPV interval is the widest because
it is based on only 88 positives. With 500 patients the estimates are adequate but not
precise; a laboratory would report the intervals, not just the point estimates.

**Step 6 — patient communication.** "Your test was positive. About two out of three
people with a positive result in this group do have the condition, so we will confirm it
with a second, more specific test before starting treatment." That sentence avoids the
common error of saying "the test is 90 % accurate, so you probably have it", and avoids
the opposite error of dismissing a positive result because of false positives.

**Step 7 — false negatives matter.** Missing 9 % of cases is a serious failure for a
treatable disease, even though 9 % sounds small. The asymmetry of costs drives the choice
of operating threshold: lower the cut-off to catch more cases and you accept more false
positives and a lower PPV. This trade-off is made explicit in case study A4, which builds
the full ROC curve and chooses a threshold against stated costs.

**Common errors.** (i) Reporting sensitivity as "the chance the test is right". (ii)
Computing PPV from sensitivity and specificity alone, without prevalence. (iii) Using
accuracy to compare tests across populations with different prevalence. (iv) Giving a
normal-approximation interval for a proportion of 0.985, which can exceed 1 — use Wilson.
