# Project datasets

Nine synthetic datasets for the [project-based learning section](../../projects/index.md). Each
is generated by `tools/generate_project_data.py` with a fixed seed, so the files are reproducible
byte for byte:

```bash
python tools/generate_project_data.py          # rewrite every file
python tools/generate_project_data.py --check  # verify nothing has drifted
```

No file describes real people, institutions, loans or matches. The generating mechanism is
documented in the script's docstrings; do not edit a CSV by hand, because the analyses in the
reference solutions depend on the values.

| File | Rows | Columns | Seed | What it contains |
|---|---|---|---|---|
| `student_performance_project.csv` | 480 | 9 | 1101 | Attendance, study hours, prior GPA, part-time work, exam marks |
| `diagnostics_project.csv` | 1,600 | 7 | 1202 | Disease status, biomarker, test result, age, severity |
| `ecommerce_experiment_project.csv` | 12,000 | 8 | 1303 | A/B variant, device, channel, conversion, revenue |
| `manufacturing_project.csv` | 900 | 7 | 1404 | Line, shift, temperature, pressure, batch size, defects |
| `weather_project.csv` | 3,288 | 7 | 1505 | Three stations, three years of daily temperature, rain, humidity |
| `credit_risk_project.csv` | 2,000 | 8 | 1606 | Score, income, loan, term, DTI, region, default |
| `cricket_project.csv` | 260 | 10 | 1707 | Teams, venue, toss, runs, outcome, margin |
| `model_uncertainty_project.csv` | 2,400 | 6 | 1808 | Two model versions, predicted probability, outcome, segment |
| `capstone_project.csv` | 1,400 | 10 | 1909 | Subscription customers: plan, tenure, spend, tickets, churn |

## Designed structure

The datasets are not random noise. Each contains a specific structure the projects ask you to
find, and at least one deliberate trap:

- **Student performance** — study hours dominate; the part-time effect is non-significant raw but
  significant adjusted, because adjustment reduces residual variance.
- **Diagnostics** — sensitivity is high but PPV falls steeply at low prevalence; the laboratory
  threshold is close to, but not at, the cost-optimal threshold.
- **E-commerce** — conversion rises with no change in basket size; the device subgroups differ in
  base rate but not much in lift.
- **Manufacturing** — over-dispersed counts; the line effect is larger than the temperature
  effect that a naive regression would promote.
- **Weather** — zero-inflated rainfall with a seasonal wet-day probability; a pooled normal model
  is badly wrong.
- **Credit risk** — a strong score effect, a null term effect, and a cut-off that depends on the
  loss assumption.
- **Cricket** — a real home advantage and a toss effect that is pure noise; small-group rankings
  are unstable.
- **Model uncertainty** — two versions with similar AUC and different calibration; precision at a
  fixed threshold is an artefact of scale.
- **Capstone** — a real ticket–churn gradient, plus a plan coefficient that reverses after
  conditioning on spend.
